# Word Tiers & Vocabulary Replacement Guide

> **Authority: Tier 3 Reference Leaf for `/deslop`**  
> *"Stock AI vocabulary creates an immediate machine scent. Replace with concrete domain verbs or eliminate entirely."*

---

## 1. Tier 1: Replace by Default (P1 Smells)

These words appear with extreme statistical overrepresentation in LLM output. Replace on first sight:

| Flagged Word / Phrase | Why It Fails | Recommended Replacement |
| :--- | :--- | :--- |
| **delve** | Prototypical AI verb for exploration | *examine, inspect, study, explore, investigate* |
| **tapestry** | Overused metaphorical inflation | *collection, system, architecture, structure* |
| **testament** | Significance inflation (*"a testament to..."*) | *shows, demonstrates, proves, evidence of* |
| **pivotal** | Unearned drama on routine work | *key, important, major, primary* |
| **revolutionize** | Marketing hyperbole | *changes, replaces, improves, upgrades* |
| **beacon** | Thematic melodrama | *standard, reference, guide* |
| **meticulous** | Unearned self-praise | *thorough, careful, detailed* |
| **multifaceted** | Pompous substitute for complex | *varied, multi-part, compound* |
| **realm** | Mythologizing technical domains | *domain, field, area, scope* |
| **foster** | Soft therapeutic jargon | *encourage, build, support, enable* |

---

## 2. Tier 2: Replace on Saturation (P2 Polish)

Replace when two or more appear in the same paragraph:

* **robust**: Replace with *stable, typed, error-handled, resilient, reliable*.
* **streamline**: Replace with *simplify, speed up, automate, cut*.
* **harness**: Replace with *use, run, apply, leverage*.
* **leverage**: Replace with *use, apply, call*.
* **seamless**: Replace with *integrated, automatic, direct*.
* **empower**: Replace with *allow, enable, support*.
* **crucial / vital**: Replace with *needed, required, important*.

---

## 3. Boilerplate Transition Phrases (Eliminate)

* `"In today's fast-paced digital world..."` $\rightarrow$ **Cut**. Lead with the topic.
* `"Furthermore, it is worth noting that..."` $\rightarrow$ **Cut**. State the fact.
* `"At the end of the day..."` $\rightarrow$ **Cut**.
* `"In conclusion, the future looks bright..."` $\rightarrow$ **Cut**. Conclude on verifiable next steps.
